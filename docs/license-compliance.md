# การปฏิบัติตามลิขสิทธิ์และ License (License Compliance)

สถานะเอกสาร: ตรวจล่าสุด 2026-10-28 — ครอบคลุมโค้ดทุกไฟล์ใน repo และแหล่งอ้างอิงทุกตัวที่ใช้

## สรุปสั้น ๆ

- **โค้ดใน repo นี้ 100% เขียนใหม่ (clean-room)** ระหว่างการพัฒนา ไม่มีการคัดลอก/แปลง/โยกย้ายโค้ดจากโปรเจกต์อื่นเข้ามาแม้แต่บรรทัดเดียว
- **ไม่มี dependency ภายนอก** — `Package.swift` ไม่ประกาศ dependency ใด ๆ ทั้งสิ้น (ทุกอย่างใช้ Foundation/AppKit/AVFoundation ของ Apple เท่านั้น)
- แหล่งอ้างอิงภายนอกถูกใช้เฉพาะในรูปแบบ **"ข้อเท็จจริงของฟอร์แมต"** (fact) ซึ่งไม่อยู่ภายใต้ลิขสิทธิ์ — รายละเอียดต่อโปรเจกต์ด้านล่าง

## โครงการอ้างอิงทีละตัว

### 1. RePKG — https://github.com/notscuffed/repkg
- **License:** MIT
- **สิ่งที่ใช้:** ข้อเท็จจริงเกี่ยวกับโครงสร้าง .pkg (มี version string, entry table, data blob) — เทียบเคียงเพื่อหาจุดที่เอกสารชุมชนเก่าคลาดเคลื่อน
- **สิ่งที่ไม่ได้ใช้:** โค้ดทุกส่วน (parser เขียนใหม่จากการวิเคราะห์ไฟล์จริงของเราเอง)
- **ข้อผูกพันที่เหลืออยู่:** ไม่มีทางกฎหมาย (MIT ผูกเฉพาะกรณีคัดลอกโค้ด — ต้องแนบ copyright notice ซึ่งเราไม่ได้คัดลอก) แต่ให้ credit ไว้ใน README เพื่อเป็นธรรมกับผู้พัฒนา

### 2. linux-wallpaperengine — https://github.com/Almamu/linux-wallpaperengine
- **License:** GPL-3.0
- **สิ่งที่ใช้:** พฤติกรรมการทำงานระดับมโนทัศน์ (เช่น วอลเปเปอร์เล่นอยู่ระดับ desktop, mute ตอนเปิดใหม่) — ใช้เป็น "ข้อมูลพฤติกรรม" เท่านั้น
- **สิ่งที่ห้ามและไม่เคยทำ:** คัดลอกโค้ด, คัดลอกโครงสร้างโค้ด, แปลงภาษา (transcribe) — GPL-3.0 ติดเงื่อนไข copyleft กับงานที่ derive จากโค้ด ซึ่ง repo นี้ไม่ใช่
- **ข้อผูกพันที่เหลืออยู่:** คงกติกาเดิมไว้ — ห้ามคัดลอกโค้ดจากโปรเจกต์นี้เข้า repo เด็ดขาด และห้ามอ่านโค้ดแล้วไปเขียนในลักษณะที่ copy โครงสร้าง กรณีสงสัยให้ถือว่าห้าม

### 3. WallpaperExtractor — https://github.com/justin1dev1/WallpaperExtractor (Apache-2.0)
- **สิ่งที่ใช้:** ข้อเท็จจริงว่าไฟล์ .tex มีหลายรุ่น (TEXV0 เก่า vs TEXV0005 ปัจจุบัน)
- **ข้อผูกพันที่เหลืออยู่:** ไม่มี (ไม่ได้คัดลอกโค้ด; NOTICE ไม่จำเป็นเพราะไม่มี derivative work)

### 4. LZ4 — https://github.com/lz4/lz4 (โค้ด BSD-2-Clause, format spec สาธารณะ)
- **สิ่งที่ใช้:** **เฉพาะเอกสารรูปแบบข้อมูล (block format description)** ซึ่งเผยแพร่สาธารณะเพื่อให้ implement ได้โดยไม่ต้องใช้โค้ด — `Sources/WPEParser/LZ4.swift` เขียนจาก spec เท่านั้น
- **ข้อผูกพันที่เหลืออยู่:** ไม่มีทางกฎหมาย (ไม่ได้ใช้โค้ด BSD) ให้ credit ใน README

### 5. รูปแบบไฟล์ของ Wallpaper Engine (โปรแกรมพาณิชย์ของ Krispy/Steam)
- เราศึกษาจากไฟล์ที่มีสิทธิ์อยู่แล้ว (interoperability — สิทธิ์ที่กฎหมายรองรับ เช่น EU directive 2009/24/EC แนวคิดเดียวกัน) ไม่ได้ reverse engineer เพื่อเลี่ยง DRM หรือ Steam auth
- **เครื่องหมายการค้า:** "Wallpaper Engine" เป็นเครื่องหมายการค้าของเจ้าของเดิม — repo นี้ตั้งชื่อ `wall` และอธิบายตัวเองว่าเป็น "compatible player" เท่านั้น ไม่ใช้ชื่อหรือโลโก้ของเจ้าของเดิมในทางที่ทำให้เข้าใจผิดว่าเป็นผลิตภัณฑ์อย่างเป็นทางการ
- **คอนเทนต์วอลเปเปอร์:** แอปไม่รวม/ไม่แจกจ่ายคอนเทนต์ใด ๆ — เล่นได้เฉพาะไฟล์ที่ผู้ใช้มีสิทธิ์อยู่แล้ว (subscribe ด้วย Steam หรือสร้างเอง)
